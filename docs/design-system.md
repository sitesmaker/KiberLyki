# Общая тема КиберЛуки

Цвета, шрифт Manrope и базовые радиусы определены один раз в `server/public/club-theme.css`.

- React импортирует этот файл через `client/src/index.css`; Vite включает его в CSS production-сборки.
- Laravel загружает его из `admin.css`; устанавливать Node.js для Blade-панели не требуется.
- Общие компоненты клиента (шапка, футер, кнопки, поля, карточки, составы, сетка, уведомления) используют CSS-переменные темы.
- Главная сохраняет свой видеоблок и декоративные градиенты. Шапка и футер больше не имеют отдельных правил только для главной.
- Панель использует ту же палитру и шрифт, с более плотной компоновкой таблиц и форм. На мобильных экранах доступны раскрывающееся меню и прокрутка таблиц внутри карточек.
- Красные сообщения и действия удаления, жёлтые предупреждения и отметки победителя сохраняют смысловые цвета.

Визуально проверены десктоп и экран 390 px: команда/состав, турниры и сетка, новости, вход, кабинет/профиль и админка. Проверены общие вычисленные цвета и шрифты в обеих частях приложения. Проверки кода: lint/build React, компиляция Blade и интеграционный тест страниц панели.
