# Главная КиберЛуки

Главная переработана в тёмном спортивном стиле, с мятным акцентом, крупной типографикой и исходным фоновым видео.

- Первый экран: заголовок и описание берутся из раздела «Первый экран» Laravel. Перенос строки в заголовке выделяет последнюю строку мятным цветом. Загруженное видео сохранено; есть пауза и поддержка prefers-reduced-motion.
- О клубе: заголовок и описание берутся из раздела «О клубе» Laravel; абзацы разделяются пустой строкой.
- Дисциплины: карточки ведут в каталог турниров с выбранной игрой через `?game=`.
- Турниры: данные из API; фильтры работают без перезагрузки. Истёкшая/ещё не начавшаяся регистрация исключается из блока открытых соревнований.
- Команды: данные из API, ссылки ведут к существующим составам.
- Блок участия: создание команды, выбор турнира, просмотр соревнований.
- Сообщество: ссылки пользователя на VK-группу и создателя; личные сведения, адрес и биография пока не добавлены.
- Футер: убраны тестовый телефон, email, расписание и пустые ссылки на соцсети.

Основная разметка: `client/src/pages/Home.tsx`, стили: `Home.css`, первый экран: `components/FullScreen`. Ссылки на сообщество собраны в `client/src/config/club.ts`.

Начальный заголовок и описание для нового дизайна записываются командой:

```powershell
cd server
php artisan db:seed --class=HomepageContentSeeder
```

Команда меняет редакционные поля первого экрана и раздела «О клубе», сохраняя существующее видео и изображения. Не запускайте её повторно, если уже отредактировали эти тексты в панели и хотите их сохранить.

Проверены: десктоп, мобильный экран 390 px, пауза видео, фильтр турниров на главной и переход из карточки игры в отфильтрованный каталог. Основатель и группа предоставлены пользователем; VK-страницы не удалось прочитать, поэтому тексты не содержат неподтверждённых персональных сведений.
