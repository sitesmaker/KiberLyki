# SEO и публикация

В `/admin/seo` выберите страницу в select: главная, список новостей, список турниров, конкретный опубликованный турнир или новость. На экране только Title и Description выбранной страницы, рядом — живые превью. В раскрывающемся блоке Open Graph можно задать отдельные заголовок, описание и изображение ссылки. Пустые значения берутся автоматически из страницы. Там же отдельно можно запретить индексацию выбранной страницы.

Название сайта и индексация всего сайта находятся в отдельном раскрывающемся блоке «Общие настройки сайта». Домен отображается автоматически из текущего HTTP-запроса; сохранённый ранее домен из базы больше не используется. Ранее заполненные SEO записей сохраняются как автоматические значения; новые настройки хранятся отдельно для каждой страницы и не меняют её содержимое.

Laravel формирует title, description, canonical, robots, Open Graph, Twitter Card и JSON-LD. Главная, список новостей, отдельные новости, список турниров и отдельные турниры также получают полное содержимое HTML через Blade: тексты, изображения, ссылки, правила, принятые команды и результаты матчей видны без JavaScript. SEO редактируется в прежнем разделе админки; изменения текста и SEO появляются при следующем запросе без пересборки.

`npm run build` в `client` сохраняет сборку в `server/public/site`. В production веб-сервер направляется на `server/public`. Нельзя раздавать `site/index.html` напрямую для всех маршрутов: это обойдёт серверное содержимое, динамические метаданные и корректные 404.

На серверных страницах React подключает независимые интерактивные блоки: меню, фильтры турниров, ручной слайдер сотрудников, турнирную сетку, заявку и инструменты организатора. Основное содержимое страницы остаётся HTML Laravel. Данные турнира для первого показа передаются вместе с HTML; ожидание отдельного запроса API не требуется. Персональные данные капитанов и ожидающие заявки в HTML не передаются. Ссылки между страницами выполняют обычную навигацию. Кабинет, команды и истории сотрудников сохраняют React-интерфейс и noindex.

В разработке Vite запрашивает серверные страницы у Laravel и подключает исходный React с HMR. Перед первым запуском нужна сборка, а backend должен быть запущен. Остальные маршруты продолжают использовать обычный React SPA.

Постоянный Node.js-процесс, VPS, браузер для генерации страниц и фоновые задачи для SEO не нужны: достаточно PHP-хостинга с расширениями Laravel и PhpSpreadsheet. Node.js используется только при сборке JS/CSS локально или в CI. После обновления шаблонов на хостинге обновите кеш представлений (`php artisan view:cache`).

При размещении сайта и API на одном домене оставить `VITE_API_URL=` и `SITE_URL=` пустыми: внутренние запросы и изображения используют текущий домен, canonical, Open Graph и sitemap формируются по адресу запроса. Vite в разработке проксирует API, загрузки и админку; `DEV_API_URL` задаёт только адрес локального backend и не попадает в сборку. При смене домена не нужно менять SEO каждой страницы или пересобирать React ради адреса API.

`APP_URL` используется для консольных задач. `SITE_URL` — необязательный фиксированный основной домен при нескольких алиасах или отдельном API. Для отдельных доменов API/клиента явно настроить `VITE_API_URL`, `FRONTEND_URL` (CORS) и `SITE_URL`. При HTTPS через reverse proxy указать адреса доверенных прокси в `TRUSTED_PROXIES`, чтобы корректно учитывать forwarded host/proto. В production использовать `APP_DEBUG=false`.

`/sitemap.xml` содержит главную, списки новостей и турниров, опубликованные новости и турниры. Команды (включая список команд), черновики, личные разделы и страницы с запретом индексации исключены. Страницы команд остаются доступны, но получают noindex. Новости доступны по slug или documentId, canonical и sitemap используют slug, если он заполнен. Список новостей имеет обычную нумерованную пагинацию и доступные роботам ссылки; страницы начиная со второй получают собственный canonical с `?page=N`. Параметры фильтров турниров не создают новые canonical.

`/robots.txt` и meta robots управляются настройками. Для localhost, loopback и доменов `.test` индексация всегда отключена. Админка и личные разделы имеют noindex. После публикации sitemap можно отправить в Google Search Console и Яндекс Вебмастер; наличие тегов не гарантирует позиции или сроки индексации.
