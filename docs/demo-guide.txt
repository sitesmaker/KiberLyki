KiberLyki — инструкция по демонстрации
=====================================

1. Запуск проекта
-----------------
Откройте два терминала.

Терминал 1 (Strapi):
  cd D:\Projects\KiberLyki\backend
  npm run dev

Терминал 2 (React):
  cd D:\Projects\KiberLyki\client
  npm run dev

После запуска откройте адрес, который покажет Vite (обычно http://localhost:5173).
Админ-панель Strapi: http://localhost:1337/admin

2. Что уже заполнено
--------------------
- 4 команды, в каждой по 5 игроков;
- у каждой команды выбрано несколько дисциплин;
- у игроков заполнены никнейм, имя, страна и описание;
- 3 турнира: завершённый, проходящий сейчас и будущий;
- у завершённого и текущего турниров заполнены сетки, команды и счёт;
- все логины и пароли находятся в файле demo-access.txt.

3. Команды и профили
--------------------
Страница /teams показывает список команд. Нажмите на карточку команды, чтобы открыть
/teams/:documentId. Слева расположен состав в виде вкладок. Справа показан выбранный
игрок: никнейм, настоящее имя, страна, роль и описание.

Капитан входит в /cabinet и может:
- выбрать несколько дисциплин команды;
- создать новый аккаунт игрока;
- добавить уже зарегистрированного игрока по username или email;
- удалить игрока из активного состава;
- передать права капитана другому активному игроку;
- выбрать состав и подать заявку на будущий турнир.

Игрок открывает «Мой профиль» и сам заполняет никнейм, имя, фамилию, страну и текст
о себе. Там же он может сменить временный пароль.

4. Как работает турнирная сетка
-------------------------------
Использован формат Single Elimination — после одного поражения команда выбывает.

- В первом раунде команды разбиваются на пары.
- Организатор вводит итоговый счёт матча.
- Команда с большим счётом помечается как победитель и попадает в следующий раунд.
- Проигравшая команда помечается как выбывшая.
- Победитель финала становится победителем всего турнира.
- Название любой команды в сетке является ссылкой на её страницу и состав.

На странице турнира дополнительно показываются статус матча, номер матча, счёт,
список допущенных команд и номер посева. Для завершённого турнира сверху отображается
чемпион.

5. Статусы
----------
Турнир (phase):
- draft — черновик, турнир ещё не готов к публикации;
- registration — капитаны могут подавать заявки в разрешённый период;
- check_in — регистрация закрыта, организатор подтверждает участников;
- active — турнир идёт, результаты заносятся в сетку;
- finished — финал завершён и победитель определён;
- cancelled — турнир отменён.

Заявка (registrationStatus):
- pending — ожидает решения организатора;
- approved — команда допущена к турниру;
- rejected — заявка отклонена;
- withdrawn — капитан сам отозвал заявку до начала турнира.

Матч (matchStatus):
- pending — состав пары ещё не определён полностью;
- scheduled — обе команды известны, матч запланирован;
- live — матч идёт сейчас;
- finished — счёт зафиксирован и победитель определён.

Участие игрока в команде (membershipStatus):
- invited — игрок приглашён, но ещё не активен;
- active — игрок находится в текущем составе;
- left — игрок самостоятельно покинул команду;
- removed — капитан удалил игрока из состава.

6. Готовые сценарии
-------------------
Завершённый: «Dota 2: Кубок Легенд» — чемпион Northern Wolves.
Текущий: «CS2: Осенний штурм» — полуфиналы завершены, финал идёт.
Будущий: «Valorant: Neon Open» — регистрация открыта.

Для проверки кабинета войдите как frostcaptain с паролем из demo-access.txt.
Для проверки управления заявками и сеткой войдите как demo-organizer.

7. Повторное заполнение демоданными
----------------------------------
Если нужно вернуть исходный демонстрационный набор:
  cd D:\Projects\KiberLyki\backend
  npm run build
  npm run seed:demo

Команда удалит текущие команды, турниры, заявки и матчи, затем создаст демонстрационный
набор заново. Новости и остальные разделы сайта она не удаляет.
