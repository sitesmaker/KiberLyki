# Демонстрационные данные

Добавить набор в локальную Laravel-базу:

```powershell
cd server
php artisan db:seed --class=DemoSeeder
```

Повторный запуск не создаёт дубликаты и не сбрасывает вручную изменённые команды, заявки, результаты или пароли. Существующие записи сохраняются. Набор разрешён только в окружениях `local` и `testing`.

Набор добавляет 32 команды, по 8 человек в составе: 5 основных игроков, 2 запасных и тренер. Команды участвуют в нескольких дисциплинах. Ещё 8 игроков свободны — их можно добавить в состав по email. По 12 играм создаётся 60 турниров; существующие дисциплины переиспользуются по slug.

Для каждой игры есть пять сценариев:

- Открытый кубок: регистрация действует ещё 30 дней, есть принятые, ожидающие, отклонённые и отозванные заявки. Две команды пока не подавали заявку.
- Квалификация: 6 принятых заявок и 2 на рассмотрении. Можно принять/отклонить заявки и сгенерировать сетку; при 6 командах будут автоматические проходы.
- Премьер-лига: сетка на 8 команд, сыграны 3 матча. Можно записать оставшиеся результаты до финала.
- Кубок чемпионов: полностью сыгранный турнир с победителем и всей историей матчей.
- Зимний сезон: неопубликованный черновик, доступен в панели для редактирования и публикации.

Все новые турниры отмечены `[Демо]`, логины тестовых аккаунтов начинаются с `mock.`. Данные намеренно вымышленные; почта использует зарезервированный домен `example.test`.

## Тестовые входы

Общий пароль новых тестовых аккаунтов: `DemoPlay2026!`.

| Аккаунт | Email | Где проверять |
|---|---|---|
| Организатор | `mock.organizer@example.test` | `/admin`, рассмотрение заявок, сетка и результаты |
| Капитан Aurora | `mock.captain01@example.test` | React `/cabinet`, состав команды и заявки |
| Капитан Iron Ravens | `mock.captain02@example.test` | Другие дисциплины и турниры |
| Игрок Aurora | `mock.team01.p2@example.test` | Личный профиль и ограничения прав |
| Свободный игрок | `mock.free01@example.test` | Добавление существующего игрока в команду |

Капитаны пронумерованы от `mock.captain01` до `mock.captain32`; свободные игроки — от `mock.free01` до `mock.free08`. Пароли прежних пользователей и администратора не меняются.

После добавления в текущую базу: 14 дисциплин (включая 2 прежние дублирующие), 36 команд, 300 пользователей, 63 турнира, 174 матча, 370 заявок и 1370 записей игроков в заявках. Перед первым запуском создана локальная копия `server/database/cyberluki-before-demo-20261016.sqlite`.
